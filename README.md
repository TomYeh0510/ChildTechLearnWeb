1. 3D 建模與列印（**已推出**：五層路線、分齡細節與活動卡、軟體階梯、安全與檢查、教材資源）

3. 實體運算與機器人（即將推出）
4. AI 人工智慧（即將推出）
5. 軟體應用與數位素養（即將推出）
