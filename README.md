# 小小創客階梯 MakerSteps

兒童科技學習路線圖。

幼兒到國中（3–15 歲）的科技學習路線，分五個年齡段、五條路線：

1. 3D 建模與列印（已完成細節）
2. 程式設計
3. 實體運算與機器人
4. AI 人工智慧
5. 軟體應用與數位素養

## 檔案

| 檔案 | 用途 |
