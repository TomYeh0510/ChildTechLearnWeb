# 一起玩科技 Tech Together

親子實作與玩具教具設計。

Tom 為女兒設計的名牌、玩具與教具的介紹與導流，加上幼兒到國中的學習探索，長期評估線上與實體列印課程。

四個入口：

1. 首頁：主張、精選作品、活動入口
2. 作品：名牌（待照片與賣場連結）、玩具與教具（已有構成三角形），連到賣貨便與 MakerWorld
3. 親子活動：用教具或一般材料的玩法
4. 學習探索：年齡總覽、五層路線、分齡細節與課表、軟體階梯、安全與檢查、教材資源
